# Changelog

All notable changes to the `docx2typst` project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-09-30

### Added
- **Core DOCX Reader**:
  - Unpack and extract raw XML streams from `.docx` ZIP packages (`word/document.xml`, `word/_rels/document.xml.rels`, `word/numbering.xml`).
  - Robust error handling with custom `DocxReadError` and `DocxParseError` classes.
- **Text & Style Extractor**:
  - Parse body paragraphs (`w:p`) and text runs (`w:r`, `w:t`).
  - Extract character formatting including bold (`w:b`), italic (`w:i`), and underline (`w:u`).
  - Extract paragraph style identifiers (`w:pStyle`) such as `Heading1` through `Heading6`.
  - Configurable whitespace preservation (`xml:space="preserve"`).
- **Numbering & Lists**:
  - Parse numbering definitions (`w:abstractNum`, `w:num`, `w:lvl`).
  - Resolve bullet (`- `) and numbered (`+ `) list items with multi-level indentation.
- **Table Support**:
  - Parse table structures (`w:tbl`, `w:tr`, `w:tc`).
  - Calculate grid column count and handle multi-paragraph cells.
  - Detect header rows and emit Typst `table.header(...)` blocks.
- **Image Support**:
  - Extract inline drawing metadata (`w:drawing`, `wp:inline`).
  - Map relationship IDs to media targets (`word/media/*`).
  - EMU dimension calculation to percentage width (`#image("...", width: XX%)`).
  - `saveImages` utility to write embedded images from archive to filesystem.
- **Typst Converter**:
  - Convert structured DOCX document model into Typst markup.
  - Escape Typst syntax characters (`\`, `#`, `@`, `<`, `>`, `` ` ``).
  - Paragraph spacing and custom header comment options (`// Generated by docx2typst`).
- **CLI Executable (`docx2typst`)**:
  - Convert one or more `.docx` files to `.typ` files.
  - Support flags: `--text-only`, `--stdout`, `--header`, `--images-dir`, `--no-escape`, `-h`/`--help`, `-v`/`--version`.
  - Graceful error handling and exit codes.
- **High-level Convenience APIs**:
  - `convertDocxFile(filePath, options)`: Full Typst conversion pipeline.
  - `convertDocxToText(filePath, options)`: Direct plain text extraction pipeline.
- **Comprehensive Test Suite**:
  - Unit tests covering all extractors, converters, CLI, and error conditions.
  - End-to-end integration tests verifying real in-memory DOCX archives via JSZip.
