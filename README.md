# docx2typst

[![npm version](https://img.shields.io/npm/v/docx2typst.svg)](https://www.npmjs.com/package/docx2typst)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)

Convert .docx files to Typst markup. Works locally, no cloud dependencies.

`docx2typst` is a fast, standalone TypeScript library and command-line tool that parses OpenXML (.docx) documents directly from their raw XML structure and translates them into clean, idiomatic [Typst](https://typst.app/) markup format.

---

## Features

- **Headings**: Maps Word styles (`Heading 1` through `Heading 6`) to Typst heading markers (`= `, `== `, etc.).
- **Rich Text Formatting**: Accurately preserves **bold** (`*text*`), *italic* (`_text_`), and <u>underline</u> (`#underline[text]`), handling whitespace and nested styling correctly.
- **Lists & Numbering**: Extracts numbering definitions to output unordered bullet lists (`- `) and ordered numbered lists (`+ `) with multi-level nesting and indentation.
- **Tables**: Parses table grids, column spans, multi-paragraph cells, and header rows using Typst `#table(...)` and `table.header(...)`.
- **Inline Images**: Detects inline drawings (`w:drawing`), extracts image binaries from the DOCX ZIP archive, calculates proportional page widths from EMUs, and generates Typst `#image(...)` calls.
- **Character Escaping**: Automatically escapes Typst reserved syntax characters (`@`, `#`, `<`, `>`, `` ` ``, `\`).
- **CLI & API**: Use it as a command-line tool for batch processing or import it as a TypeScript/JavaScript module.
- **TypeScript-First**: Zero external binary dependencies, full typing declarations, and ESM/CommonJS compatibility.

## Installation

Install as a project dependency:

```bash
npm install docx2typst
```

## Quick Start

### Library Usage

```typescript
import { writeFile } from 'node:fs/promises';
import { convertDocxFile } from 'docx2typst';

// Convert a .docx document to Typst markup
const result = await convertDocxFile('./document.docx', {
  includeHeader: true,
  imageOutputDir: 'images',
});

// Output markup content
console.log(result.content);

// Inspect conversion statistics
console.log(`Paragraphs: ${result.stats.paragraphCount}`);
console.log(`Headings: ${result.stats.headingCount}`);
console.log(`Formatted runs: ${result.stats.runsWithFormatting}`);

// Save to disk
await writeFile('./document.typ', result.content, 'utf-8');
```

### Extract Plain Text Only

If you only need to extract plain text without Typst markup:

```typescript
import { convertDocxToText } from 'docx2typst';

const plainText = await convertDocxToText('./document.docx');
console.log(plainText);
```

## CLI Usage

The package includes a standalone CLI executable `docx2typst`.

```bash
docx2typst [options] <files...>
```

### Options

| Flag | Description |
|---|---|
| `--text-only` | Extract plain text instead of Typst markup |
| `--stdout` | Print converted output to `stdout` instead of writing a file |
| `--header` | Prepend `// Generated by docx2typst` header comment |
| `--images-dir <dir>` | Directory for extracted image paths (default: `images`) |
| `--no-escape` | Disable Typst special character escaping |
| `-h`, `--help` | Show usage information and exit |
| `-v`, `--version` | Show package version and exit |

### Examples

Convert a single `.docx` file (creates `notes.typ` in the same directory):

```bash
docx2typst notes.docx
```

Convert multiple documents in batch:

```bash
docx2typst chapter1.docx chapter2.docx chapter3.docx
```

Print Typst markup directly to standard output or pipe to another tool:

```bash
docx2typst --stdout report.docx > report.typ
```

Extract plain text to stdout:

```bash
docx2typst --text-only --stdout report.docx
```

Include generated header and customize images output directory:

```bash
docx2typst --header --images-dir ./assets/media report.docx
```

## API Reference

### High-Level Functions

#### `convertDocxFile(filePath, options?): Promise<TypstDocument>`
Reads a `.docx` file from disk, parses its body XML and numbering definitions, and produces a complete Typst document with conversion metrics.

```typescript
function convertDocxFile(
  filePath: string,
  options?: TypstConverterOptions,
): Promise<TypstDocument>;
```

#### `convertDocxToText(filePath, options?): Promise<string>`
Reads a `.docx` file from disk and returns the extracted plain text with normalized newlines.

```typescript
function convertDocxToText(
  filePath: string,
  options?: DocxParserOptions,
): Promise<string>;
```

### Core Extraction & Parsing APIs

#### `readDocxFile(filePath: string): Promise<RawXmlContent>`
Loads a `.docx` archive using JSZip and extracts `word/document.xml`, `word/_rels/document.xml.rels`, and `word/numbering.xml`.

#### `extractText(documentXml: string, options?: DocxParserOptions, imageMap?: Map<string, DocxImage>): DocxDocument`
Parses the main document XML into paragraphs, styled text runs, headings, tables, and images.

#### `extractNumberingMaps(numberingXml: string): { numIdMap: NumIdMap; abstractNumMap: AbstractNumMap }`
Parses `word/numbering.xml` to construct numbering ID and list format lookup mappings.

#### `resolveListItems(document: DocxDocument, numIdMap: NumIdMap, abstractNumMap: AbstractNumMap): DocxDocument`
Resolves numbering properties (`w:numPr`) on paragraphs to determine bullet vs. numbered list types and indentation levels.

#### `extractTables(documentXml: string): DocxTable[]`
Extracts structured tables (`w:tbl`), rows, cells, and header flags.

#### `convertDocxToTypst(doc: DocxDocument, options?: TypstConverterOptions): TypstDocument`
Converts an in-memory `DocxDocument` representation into Typst markup string and conversion stats.

#### `convertTableToTypst(table: DocxTable, options?: TypstConverterOptions): string`
Converts a single `DocxTable` object into a Typst `#table(...)` expression.

#### `saveImages(imageMap: Map<string, DocxImage>, zipInstance: unknown, outputDir?: string): Promise<number>`
Writes extracted images from the document archive to a destination folder on disk.

#### `getHeadingLevel(style: string | undefined): number | null`
Evaluates a paragraph style string (e.g. `'Heading1'`, `'Heading 2'`) and returns a number from 1 to 6, or `null`.

#### `parseXml(xmlString: string): Record<string, unknown>`
Parses raw XML string using `fast-xml-parser` configured for OOXML tag conventions.

### Error Classes

- **`DocxReadError`**: Thrown when a `.docx` file cannot be read from disk, is not a valid ZIP archive, or is missing required XML parts.
- **`DocxParseError`**: Thrown when XML content inside the archive is malformed.

## Supported OOXML Elements

| OOXML Element | Typst Output | Support Status | Notes |
|---|---|:---:|---|
| `w:p` | Paragraph block | Supported | Handled with spacing and list indentations |
| `w:r` | Text run | Supported | Formatting combined and nested |
| `w:t` | Text content | Supported | Supports `xml:space="preserve"` |
| `w:pStyle` | `= Heading` | Supported | Levels 1 through 6 (`Heading1` - `Heading6`) |
| `w:b`, `w:bCs` | `*bold*` | Supported | Preserves leading/trailing whitespace |
| `w:i`, `w:iCs` | `_italic_` | Supported | Preserves leading/trailing whitespace |
| `w:u` | `#underline[...]` | Supported | Wrapped around bold/italic |
| `w:numPr` (bullet) | `- Item` | Supported | Multi-level indentations |
| `w:numPr` (decimal) | `+ Item` | Supported | Multi-level indentations |
| `w:tbl` | `#table(...)` | Supported | Calculates column count dynamically |
| `w:tr` | Table rows | Supported | Formatted cell contents |
| `w:tblHeader` | `table.header(...)` | Supported | Top header rows wrapped in header blocks |
| `w:tc` | `[...]` | Supported | Supports multi-paragraph cell contents |
| `w:drawing` / `wp:inline` | `#image(...)` | Supported | Proportional page width scaling from EMUs |
| `w:hyperlink` | `#link(...)` | Planned | Future release |
| `w:footnote` / `w:endnote` | `#footnote(...)` | Planned | Future release |
| `m:oMath` (OMML) | `$formula$` | Planned | Future release |

## Options Reference

### `TypstConverterOptions`

Passed to `convertDocxFile` and `convertDocxToTypst`:

| Option | Type | Default | Description |
|---|---|:---:|---|
| `paragraphSpacing` | `boolean` | `true` | Inserts blank lines between standard paragraphs (lists remain compact). |
| `escapeSpecialChars` | `boolean` | `true` | Automatically escapes Typst reserved symbols (`@`, `#`, `<`, `>`, `` ` ``, `\`). |
| `includeHeader` | `boolean` | `false` | Adds `// Generated by docx2typst\n\n` comment at the top of the file. |
| `imageOutputDir` | `string` | `'images'` | Output folder path referenced inside `#image("path/to/img.png")`. |

### `DocxParserOptions`

Passed to `convertDocxToText` and `extractText`:

| Option | Type | Default | Description |
|---|---|:---:|---|
| `includeStyles` | `boolean` | `true` | Extracts style names (`w:pStyle`) into paragraph metadata. |
| `preserveWhitespace` | `boolean` | `true` | Preserves leading and trailing space when `xml:space="preserve"` is set. |
| `images` | `ImageExtractionOptions` | `{}` | Configures image extraction settings (`outputDir`, `enabled`). |
